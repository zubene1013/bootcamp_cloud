## Key concepts learned

- **Docker의 핵심 가치**: OS 공유를 통해 가볍고 빠른 컨테이너 기술로, 동일한 환경 실행 보장
- **Registry-Image-Container 관계**: Registry(저장소) → Image(틀) → Container(실행 프로세스)
- **Image의 특징**: Read-Only, 정적 파일, 레이어 아키텍처로 변경된 레이어만 교체 가능
- **Container의 특징**: Read-Write, 격리된 환경, 휘발성(임시), Volume으로 영속성 구현
- **Port Forwarding**: 격리된 컨테이너 접근을 위해 호스트 포트를 컨테이너 포트로 연결
- **이미지 태깅**: 이미지 ID는 동일하고 이름만 추가되는 방식으로 버전/프로파일 관리
- **untagged/dangling 이미지**: 태그 삭제 시 남는 이미지 또는 재빌드 시 식별자를 잃은 이미지
- **Docker Hub 저장소**: 이미지 업로드 시 저장소명과 이미지 태그가 일치해야 함
- **네트워크 연결**: 컨테이너를 같은 네트워크로 묶으면 컨테이너명으로 서로 통신 가능

## Commands / Configuration

### Image 명령어

```bash
# 이미지 목록 조회
docker images
docker images -q
docker images -a
docker images --format json
docker images --format "{{.ID}} {{.Repository}} {{.Tag}}"

# 이미지 세부 정보 조회
docker image inspect nginx
docker image inspect nginx -f "{{.Id}}"
docker image inspect nginx -f "{{.Config.ExposedPorts}}"

# 이미지 레이어 히스토리 조회
docker history nginx
docker image history nginx --no-trunc

# 이미지 태그 설정
docker tag nginx:latest nginx:v1

# 이미지 삭제
docker rmi IMAGE
docker rmi 0e760fdfbc48
docker rmi nginx:1.30-alpine

# 이미지를 파일로 저장
docker save -o nginx.tar nginx
docker save myimage:latest | gzip > myimage_latest.tar.gz

# 파일에서 이미지 로드
docker load -i nginx.tar

# Docker Hub에서 이미지 다운로드
docker pull ubuntu
docker pull ubuntu:24.04
docker pull -a ubuntu

# Docker Hub 로그인/로그아웃
docker login -u 사용자명
docker logout

# 이미지 업로드
docker push kyongyeolin/my-app-nginx-repo:v1
docker push -a NAME
```

### Container 명령어

```bash
# 컨테이너 생성
docker create --name my-nginx nginx
docker create --name my-nginx2 -p 1234:80 nginx
docker create --name some-mysql -e MYSQL_ROOT_PASSWORD=1234 mysql:8.3
docker create --name some-mysql2 \
  -e MYSQL_ROOT_PASSWORD=1234 \
  -v /my/own/datadir:/var/lib/mysql mysql:8.3

# 네트워크 생성 및 컨테이너 연결
docker network create full-stack
docker create --name my-db --network full-stack mysql
docker create --name my-app --network full-stack myboot

# 컨테이너 실행
docker run hello-world
docker run -d nginx:1.30-alpine
docker run -d -p 1234:80 nginx
```

### 기본 명령어

```bash
# 설치 확인
docker version

# 실행 중인 컨테이너 확인
docker ps

# 실행 중 + 종료된 컨테이너 모두 확인
docker ps -a
```
