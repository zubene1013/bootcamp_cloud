## Key concepts learned

- **RuntimeException 계열 예외**: Spring에서 발생하는 모든 예외는 RuntimeException 계열이므로 try~catch를 사용하지 않고 어노테이션 기반 선언적 예외처리 사용
- **@ExceptionHandler**: 특정 Controller 내에서만 발생하는 예외를 처리하는 어노테이션
- **@ControllerAdvice**: 모든 Controller에서 발생하는 예외를 일괄 처리하는 전역 예외처리
- **@Valid + BindingResult**: 화면이 있는 경우 사용자 입력 데이터를 검증하며, 검증 어노테이션은 DTO에 적용
- **@Validated**: 검증 어노테이션을 DTO가 아닌 Controller의 메서드 파라미터에 직접 적용 가능
- **Thymeleaf**: Spring Boot에서 기본으로 지원하는 서버 사이드 템플릿 엔진으로 th: 속성을 사용하여 동적으로 데이터 렌더링
- **th:object와 *{}**: 객체를 선택하여 중첩된 속성에 접근할 때 사용
- **th:each**: Thymeleaf에서 반복문을 처리하며, index, count, first, last 등의 상태 변수 제공
- **@{} 문법**: Thymeleaf에서 경로와 링크를 처리하는 문법으로 절대경로, 상대경로, 파라미터 전달 지원
- **Thymeleaf 유틸리티 객체**: #temporals, #strings, #numbers, #lists 등을 통해 날짜, 문자열, 숫자, 리스트 데이터 처리
- **th:fragment와 th:replace**: 화면의 공통 부분을 조각으로 정의하고 재사용 가능

### Spring Boot 예외처리 및 검증

#### 로컬 예외처리 - @ExceptionHandler

```java
@Controller
public class MainController {
    @GetMapping("/main")
    public String main(){
        if(true) throw new IllegalArgumentException("IllegalArgumentException 예외발생");
        return "main";
    }

    @ExceptionHandler(value={IllegalArgumentException.class, NullPointerException.class})
    public String handleException(Exception ex, Model model){
        model.addAttribute("message", ex.getMessage());
        return "error/error";
    }
}
```

#### 전역 예외처리 - @ControllerAdvice

```java
@ControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(value={IllegalArgumentException.class,
                             NullPointerException.class,
                             ArithmeticException.class})
    public String handleException(Exception ex, Model model){
        model.addAttribute("message", ex.getMessage());
        return "error/error";
    }
}
```

#### @Valid + BindingResult 검증

의존성 설정:
```javascript
implementation 'org.springframework.boot:spring-boot-starter-validation'
```

DTO 작성:
```java
public class TodoDTO {
    @NotBlank(message = "적어도 한글자 이상 입력하세요")
    String userid;

    @Size(min = 5, message = "최소 5글자 이상 입력하시요")
    String description;

    @NotNull
    @FutureOrPresent(message = "현재 날짜 또는 미래 날짜 입력하시오")
    LocalDate targetDate;
}
```

Controller 작성:
```java
@GetMapping("/add-todo")
public String showTodoPage(Model model) {
    model.addAttribute("xxx", new TodoDTO());
    return "write";
}

@PostMapping("/add-todo")
public String addTodo(@Valid @ModelAttribute("xxx") TodoDTO todoDTO,
                      BindingResult bindingResult, Model model) {
    if(bindingResult.hasErrors()){
        return "write";
    }
    return "redirect:main";
}
```

Thymeleaf 템플릿:
```html
<form th:object="${xxx}" th:action="@{/add-todo}" method="post">
    아이디:<input type="text" th:field="*{userid}" ><br>
    <p th:if="${#fields.hasErrors('userid')}" th:errors="*{userid}"></p>
    할일:<input type="text" th:field="*{description}"><br>
    <p th:if="${#fields.hasErrors('description')}" th:errors="*{description}"></p>
    목표날짜:<input type="date" th:field="*{targetDate}"><br>
    <p th:if="${#fields.hasErrors('targetDate')}" th:errors="*{targetDate}"></p>
    <input type="submit" value="할일 저장">
</form>
```

#### @Validated 검증

Controller 작성:
```java
@Controller
@Validated
public class TodoController {
    @GetMapping("/add-todo")
    public String showTodoPage() {
        return "write";
    }

    @PostMapping("/add-todo")
    public String addTodo(
            @NotBlank(message = "적어도 한글자 이상 입력하세요") String userid,
            @Size(min = 5, message = "최소 5글자 이상 입력하시요") String description,
            @NotNull @FutureOrPresent(message = "현재 날짜 또는 미래 날짜 입력하시오") LocalDate targetDate) {
        return "redirect:main";
    }
}
```

전역 예외처리:
```java
@ControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(value={ConstraintViolationException.class})
    public String handleException(Exception ex, RedirectAttributes redirectAttributes){
        redirectAttributes.addFlashAttribute("errorMessage", "유효성 검증 실패");
        return "redirect:add-todo";
    }
}
```

### Thymeleaf 문법

#### Model 데이터 출력

```html
<html xmlns:th="http://www.thymeleaf.org">
<body>
    리터럴 : <p th:text="123+1"></p>
    리터럴 : <p th:text="'hello'"></p>
    request : <p th:text="${request}"></p>
    request2(HTML 허용) : <p th:utext="${request2}"></p>
    session : <p th:text="${session.session2}"></p>
    application : <p th:text="${application.application2}"></p>
</body>
</html>
```

#### 객체 속성 접근

```html
<!-- 중첩형태 -->
login객체:<p th:text="${login}"></p>
userid:<p th:text="${login.userid}"></p>
password:<p th:text="${login.password}"></p>

<!-- th:object 사용 -->
<div th:object="${login}">
    아이디:<p th:text="*{userid}"></p>
    비번:<p th:text="*{password}"></p>
</div>
```

#### 제어문 처리

```html
<!-- 조건문 -->
<p th:if="${login.userid == 'inky4832'}">참1</p>

<!-- 3항 연산자 -->
<p th:text="${login.userid == 'inky4832'}?'참3':'거짓'"></p>
<p th:class="${login.userid == 'inky4832'}?'xxx':'yyy'">css 적용된 텍스트</p>

<!-- switch -->
<div th:switch="${login.userid}">
    <p th:case="inky4832">inky4832입니다.</p>
    <p th:case="inky4833">inky4833입니다.</p>
    <p th:case="*">default 입니다.</p>
</div>

<!-- 반복문 -->
<ul th:each="dto: ${myList}">
    <li th:text="${dto.userid} + '  ' + ${dto.password}"></li>
</ul>

<!-- 반복문 상태 변수 -->
<ul th:each="dto, yyy: ${myList}">
    <li th:text="${dto.userid} + '  ' + ${yyy.index} + '  ' + ${yyy.first}"></li>
</ul>
```

#### 유틸리티 객체

```html
<!-- 날짜 유틸리티 -->
today:<p th:text="${#temporals.format(today, 'dd/MM/yyyy')}"></p>

<!-- 문자열 유틸리티 -->
<p th:text="${#strings.toUpperCase(username)}"></p>
<p th:text="${#strings.length(username)}"></p>
<p th:text="${#strings.substring(username,0,4)}"></p>

<!-- 숫자 유틸리티 -->
<p th:text="${#numbers.formatInteger(price,3,'POINT')}"></p>
<p th:text="${#numbers.formatInteger(price,3,'COMMA')}"></p>
<p th:text="${#numbers.formatCurrency(price)}"></p>

<!-- 리스트 유틸리티 -->
size:<p th:text="${#lists.size(myList)}"></p>
값이 없냐?<p th:text="${#lists.isEmpty(myList)}"></p>
값이 포함되냐?<p th:text="${#lists.contains(myList, 'A')}"></p>
```
