## Key concepts learned

- **요청 위임 (Request Delegation)**: 서블릿의 비즈니스 로직과 JSP의 화면 처리를 분리하여 유지보수성을 높이는 설계 패턴
- **forward 방식**: request 객체를 재사용하여 같은 연결 내에서 요청을 위임하며, URL은 변경되지 않고 request 속성으로 데이터 전달 가능
- **redirect 방식**: 브라우저에게 새로운 URL로 재요청하도록 지시하며, 새로운 request 객체가 생성되므로 데이터 전달 불가
- **HTTP 비연결성 (Connectionless)**: HTTP 프로토콜의 특성상 요청-응답 후 연결이 끊겨 이전 상태를 기억할 수 없음
- **세션 관리 (Session Tracking)**: 비연결성으로 인한 상태 유지 문제를 해결하기 위해 서버나 브라우저에 정보를 저장하는 기술
- **세션 (Session)**: 서버에 저장되는 사용자 상태 정보로, 같은 브라우저의 여러 요청 간에 데이터 공유 가능
- **쿠키 (Cookie)**: 브라우저에 저장되는 클라이언트 정보로, 자동으로 서버에 전송되어 자동 로그인 등에 활용

## Commands / Configuration

### Session Configuration (web.xml)

```xml
<session-config>
  <session-timeout>30</session-timeout>
</session-config>
```

### forward 방식

```java
// 방법 1: 두 줄로 작성
RequestDispatcher dispatcher = request.getRequestDispatcher("target.jsp");
dispatcher.forward(request, response);

// 방법 2: 한 줄로 작성 (권장)
request.getRequestDispatcher("target.jsp").forward(request, response);

// 데이터 전달
request.setAttribute("name", "홍길동");
request.getRequestDispatcher("target.jsp").forward(request, response);

// JSP에서 데이터 읽기
String name = (String) request.getAttribute("name");
```

### redirect 방식

```java
response.sendRedirect("target.jsp");
```

### 세션 관리

```java
// 세션 가져오기 (없으면 새로 생성)
HttpSession session = request.getSession();
HttpSession session = request.getSession(true);

// 세션 가져오기 (없으면 null 반환)
HttpSession session = request.getSession(false);

// 데이터 저장
session.setAttribute("loginUser", "홍길동");

// 데이터 조회
String user = (String) session.getAttribute("loginUser");

// 데이터 삭제
session.removeAttribute("loginUser");

// 타임아웃 설정 (초 단위)
session.setMaxInactiveInterval(1800);  // 30분
```

### 쿠키 관리

```java
// 쿠키 생성 및 저장
Cookie cookie = new Cookie("userId", "hong123");
response.addCookie(cookie);

// 쿠키 읽기
Cookie[] cookies = request.getCookies();
for (Cookie c : cookies) {
    if (c.getName().equals("userId")) {
        String userId = c.getValue();
    }
}
```
