## Key concepts learned

- **Foreground/Background 프로세스**: 명령어 끝에 `&`를 붙여 백그라운드 실행, `Ctrl+Z`로 중지, `bg`/`fg`로 전환 가능
- **crontab**: 정해진 시간에 특정 작업을 반복 실행하는 프로세스 스케줄러로, 분/시/일/월/요일/명령어 형식으로 설정
- **wget**: URL에서 파일을 다운로드하는 도구로 백그라운드(`-b`), 이어받기(`-c`), 속도 제한(`--limit-rate`) 등 옵션 제공
- **런레벨(Runlevel)**: 시스템의 동작 상태를 정의하며, 3은 CUI 모드, 5는 GUI 모드 (systemd에서는 target으로 표현)
- **쉘 스크립트**: 쉬뱅(`#!/bin/bash`)으로 시작하는 실행 가능한 텍스트 파일로, 변수, 조건문, 반복문 등 프로그래밍 기능 제공
- **Positional Arguments**: 쉘 스크립트 실행 시 `$1`, `$2` 등으로 전달된 인자에 접근
- **특수변수**: `$?`는 이전 명령어의 종료 코드 (0=성공, 그 외=실패)
- **쉘 비교 연산자**: 수치 비교(`-eq`, `-ne` 등)와 문자열 비교(`==`, `!=`), 패턴 매칭(`*` 와일드카드) 지원

## Commands / Configuration

### 프로세스 제어

```bash
top                    # 실시간 프로세스 모니터링
ps -ef | wc -l         # 실행중인 프로세스 개수
sleep 50 &             # 백그라운드 실행
jobs                   # 백그라운드/중지 프로세스 확인
kill -9 PID            # 강제 종료
bg %1                  # 중지된 프로세스를 백그라운드로 재시작
fg %1                  # 백그라운드 프로세스를 포그라운드로 복구
```

### crontab

```bash
crontab mycron.txt              # cron 등록
crontab -l                      # 현재 사용자 cron 목록
crontab -u user1 -l             # user1 cron 목록
crontab -u user1 -r             # user1 cron 삭제
```

### crontab 파일 형식

```
분   시   일   월   요일   명령어
*    *    *    *    *      echo "hello"
0    *    *    *    *      매시간마다
30   2    *    *    *      매일 2시 30분
0    0    1    1    *      매년 1월 1일
*/2  *    *    *    *      2분마다
```

### wget

```bash
sudo apt install wget -y
wget URL                        # 기본 다운로드
wget -b URL                     # 백그라운드
wget -c URL                     # 이어받기
wget -P 디렉터리 URL            # 특정 디렉터리에 저장
wget -O 파일명 URL              # 다른 이름으로 저장
wget --show-progress URL        # 진행율 확인
wget --limit-rate=10K URL       # 속도 제한
ps -ef | grep wget              # PID 찾기
kill -9 PID                     # wget 프로세스 종료
```

### init 프로세스 및 런레벨

```bash
systemctl get-default                           # 현재 런레벨 확인
sudo init 3                                     # CUI 모드 변경
sudo init 5                                     # GUI 모드 변경
systemctl set-default graphical.target          # GUI 영구 설정
systemctl set-default multi-user.target         # CUI 영구 설정
sudo init 0                                     # 시스템 종료
sudo init 6                                     # 시스템 재부팅
```

### 쉘 스크립트 - 변수

```bash
#!/bin/bash

# 변수 선언
name=kim
age=30

# 변수 사용
echo $name
echo ${age}
echo "name: $name, age: $age"   # 큰따옴표에서 변수 치환
echo 'name: $name'              # 작은따옴표에서는 치환 안 됨

# 명령어 결과를 변수에 저장
today=$(date)
list=$(ls)

# 키보드 입력
read -p "이름 입력: " name2

# 변수 조회/삭제
set | grep -w name
unset name

# 상수
readonly PI=3.14
```

### 쉘 스크립트 - Positional Arguments

```bash
#!/bin/bash
echo "file: $0"    # 파일명
echo "arg1: $1"    # 첫번째 인자
echo "arg2: $2"    # 두번째 인자

chmod 700 test2.sh
./test2.sh one two
```

### 쉘 스크립트 - 특수변수

```bash
ls /tmp
echo "$?"           # 0 출력 (성공)

ls /temp
echo "$?"           # 0이 아닌 값 출력 (실패)
```

### 쉘 스크립트 - 연산자

```bash
# 수치 비교
n=10
[[ $n -eq 10 ]]
echo "result: $?"   # 0 (성공)

# 문자열 비교
name=hello
[[ $name == "hello" ]]
echo "result: $?"   # 0 (성공)

# 패턴 매칭
[[ $name == h* ]]
echo "result: $?"
```
