## Key concepts learned

- **세션(Session)**: 서버에 저장되는 상태 유지 메커니즘으로, jsessionid를 통해 브라우저와 서버 간의 데이터를 연결하고 관리하는 기술
- **쿠키(Cookie)**: 클라이언트(브라우저)에 저장되는 String 데이터로, maxAge 설정으로 파일 저장 또는 브라우저 메모리 저장 여부를 결정
- **JSP(Java Server Page)**: 서블릿처럼 동적 컴포넌트로 작동하며, jsp → java → class → HTML 3단계 변환 과정을 거침
- **JSP 지시자(Directive)**: <%@ %> 형태로 page, include, taglib 지시자가 있으며, 변환 시점에 처리되는 선언부
- **JSP 내장객체(Implicit Object)**: request, response, session, application 등이 자동으로 생성되어 선언 없이 사용 가능한 객체
- **Model 1 Architecture**: JSP가 모든 로직을 처리하는 방식으로, 개발은 빠르지만 유지보수가 어려워 현재 사용하지 않음
- **Model 2 Architecture (MVC)**: Controller(서블릿) → Model(Service/DAO) → View(JSP) 구조로, 관심사 분리를 통해 유지보수성이 높은 패턴
- **Forward vs Redirect**: Forward는 서버 내부에서 요청을 위임하며, Redirect는 브라우저를 새 URL로 이동시키는 방식
- **BoardDTO**: 게시판 데이터를 전달하기 위한 Data Transfer Object로, 계층 간 데이터 전달에 사용

## Commands / Configuration

### 세션 관리

```java
// 세션 생성 및 데이터 저장
HttpSession session = request.getSession();
session.setAttribute("id", "aaaa");

// 세션 조회
HttpSession session = request.getSession();
String data = (String) session.getAttribute("id");

// 세션 존재 여부 확인
HttpSession session = request.getSession(false);
if (session != null) {
    String data = (String) session.getAttribute("id");
}

// 세션 전체 삭제
session.invalidate();

// 특정 세션 데이터만 삭제
session.removeAttribute("cart");
```

### 쿠키 관리

```java
// 쿠키 생성
Cookie c = new Cookie("xxx", "value");

// 쿠키 타임아웃 설정
c.setMaxAge(초단위);
// 양수: 파일에 저장 (비휘발성)
// 음수: 브라우저에 저장 (브라우저 종료시 삭제)
// 0: 즉시 삭제

// 클라이언트에 쿠키 전달
response.addCookie(c);

// 쿠키 읽기
Cookie[] cookies = request.getCookies();
for (Cookie c : cookies) {
    String key = c.getName();
    if ("xxx".equals(key)) {
        String value = c.getValue();
    }
}

// 쿠키 삭제
c.setMaxAge(0);
response.addCookie(c);
```

### JSP Directive 태그

```jsp
<%@ page contentType="text/html" %>
<%-- response.setContentType()과 동일 --%>

<%@ page import="java.util.ArrayList" %>
<%@ page import="java.util.Date" %>

<%-- include directive: .java 변환 전 포함 --%>
<%@ include file="header.jsp" %>

<%-- jsp:include: 실행 결과를 포함 --%>
<jsp:include page="header.jsp" flush="true"/>

<%-- taglib directive: JSTL 사용 --%>
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
```

### JSP 코드 구성요소

```jsp

${name}

    ${item}
</c:forEach>

<c:if test="${조건}">
    ...
</c:if>

<%-- JSP 주석 --%>
```
