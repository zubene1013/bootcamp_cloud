## Key concepts learned

- **Pod 리소스 requests/limits**: 여러 Pod가 Node의 CPU/Memory를 공유할 때 특정 Pod의 자원 독점을 방지하기 위한 설정. CPU 초과 시 Throttling, Memory 초과 시 OOMKill 발생
- **CPU 단위 (m)**: 1000m = 1 Core, 250m = 0.25 Core
- **Memory 단위**: Ki, Mi, Gi 등 사용 가능
- **Namespace**: 하나의 K8s 클러스터를 논리적으로 여러 개로 분리하는 기능. Node와 PersistentVolume은 Namespace 적용 불가
- **ReplicaSet**: 지정한 개수만큼 Pod를 항상 유지하는 감시자. selector.matchLabels와 template.metadata.labels가 반드시 일치해야 함
- **Deployment**: Pod + ReplicaSet 기능을 포함하면서 롤링업데이트, 롤백, 버전관리, 스케일링을 지원하는 실무 표준 리소스
- **롤링업데이트**: maxSurge와 maxUnavailable을 이용해 단계적으로 새 버전 Pod를 생성하고 구 버전을 삭제하는 무중단 배포 방식

## Commands / Configuration

### Pod 리소스 자원 관리

```yaml
spec:
  containers:
  - name: nginx
    image: nginx
    resources:
      requests:
        cpu: "250m"
        memory: "64Mi"
      limits:
        cpu: "500m"
        memory: "128Mi"
```

### Docker Desktop metrics-server TLS 오류 해결

```bash
kubectl patch deployment metrics-server -n kube-system \
  --type='json' \
  -p='[{"op":"add","path":"/spec/template/spec/containers/0/args/-","value":"--kubelet-insecure-tls"}]'
```

### Pod 리소스 사용량 확인

```bash
kubectl top nodes
kubectl top pods
kubectl top pods -n kube-system
```

### CPU Throttling 실습

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: stress-cpu
spec:
  restartPolicy: Never
  containers:
  - name: stress
    image: polinux/stress
    args: ["stress", "--cpu", "1", "--timeout", "120s", "--verbose"]
    resources:
      requests:
        cpu: "200m"
        memory: "64Mi"
      limits:
        cpu: "500m"
        memory: "128Mi"
```

### Memory OOMKill 실습

```yaml
args: ["stress", "--vm", "1", "--vm-bytes", "300M", "--timeout", "120s", "--verbose"]
```

### ReplicaSet

```yaml
apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: nginx-replicaset
spec:
  replicas: 3
  selector:
    matchLabels:
      app: web
  template:
    metadata:
      labels:
        app: web
    spec:
      containers:
      - name: nginx-container
        image: nginx
        ports:
        - containerPort: 80
```

```bash
kubectl apply -f replicaset.yaml
kubectl get replicaset
kubectl get pods -l app=web
kubectl delete pod <pod-name>
```

### Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 1
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: nginx
        image: nginx:1.21
        ports:
        - containerPort: 80
```

### Deployment rollout 명령어

```bash
# 이미지 변경
kubectl set image deployment/nginx-deployment nginx-container=nginx:1.25

# 배포 상태 확인
kubectl rollout status deployment/nginx-deployment

# 배포 이력 조회
kubectl rollout history deployment/nginx-deployment

# 특정 버전 상세 보기
kubectl rollout history deployment/nginx-deployment --revision=2

# 이전 버전으로 롤백
kubectl rollout undo deployment/nginx-deployment

# 특정 버전으로 롤백
kubectl rollout undo deployment/nginx-deployment --to-revision=5

# Pod 전체 재시작
kubectl rollout restart deployment/nginx-deployment

# 배포 일시 중지 / 재개
kubectl rollout pause deployment/nginx-deployment
kubectl rollout resume deployment/nginx-deployment
```

### Deployment 스케일링

```bash
# 명령형
kubectl scale deployment/nginx-deployment --replicas=5

# 선언형
kubectl apply -f deployment.yaml
```
