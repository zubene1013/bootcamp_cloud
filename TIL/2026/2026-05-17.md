## What I did

- Spring Boot에서 Controller가 브라우저 요청 데이터를 수신하는 6가지 방법 정리
- @RequestMapping의 다양한 패턴과 심화 사용법 학습
- GET/POST 요청 구분 처리 방법 학습

## Key concepts learned

- **HttpServletRequest 직접 사용**: 기존 서블릿 방식으로 request.getParameter()를 통해 파라미터를 하나씩 추출하는 방법
- **@RequestParam**: HTML form의 input name 속성값을 Controller 파라미터에 매핑하는 어노테이션
- **@RequestParam 옵션**: required와 defaultValue를 이용해 필수 여부와 기본값을 설정할 수 있음
- **DTO로 데이터 수신**: form의 input name 속성값과 DTO 필드명이 일치하면 자동으로 매핑되는 가장 실무적인 방법
- **Map으로 데이터 수신**: @RequestParam Map을 사용하면 모든 파라미터를 key-value 형태로 받을 수 있음
- **@RequestMapping 패턴**: 와일드카드(*, **)를 사용해 다양한 URL 패턴을 매핑할 수 있음
- **클래스 레벨 @RequestMapping**: 클래스에 설정하면 모든 메서드에 공통 접두사가 적용됨
- **GET/POST 구분**: 요청 매핑값이 같아도 @GetMapping/@PostMapping으로 HTTP method를 구분하여 처리 가능

## Commands / Configuration

### Controller 요청 데이터 수신 방법

```java
// 방법 1 - HttpServletRequest 직접 사용
@GetMapping("/login2")
public String hello2(HttpServletRequest request) {
    String userid   = request.getParameter("userid");
    String password = request.getParameter("password");
    return "main";
}

// 방법 2 - @RequestParam 이름 지정
@GetMapping("/login3")
public String hello3(
        @RequestParam(name = "userid") String userid,
        @RequestParam(value = "password") String password) {
    return "main";
}

// 방법 3 - 파라미터명 = 변수명이면 생략 가능
@GetMapping("/login4")
public String hello4(
        @RequestParam String userid,
        @RequestParam String password) {
    return "main";
}

// 방법 4 - @RequestParam 옵션 설정
@GetMapping("/login5")
public String hello5(
        @RequestParam(name = "userid") String userid,
        @RequestParam(
            value = "password",
            required = false,
            defaultValue = "9999"
        ) String password) {
    return "main";
}

// 방법 5 - DTO로 한 번에 받기
@GetMapping("/login6")
public String hello6(LoginDTO dto) {
    System.out.println(dto);
    return "main";
}

// LoginDTO 클래스
public class LoginDTO {
    private String userid;
    private String password;
    // Getter/Setter 필수
}

// 방법 6 - Map으로 받기
@GetMapping("/login")
public String hello(@RequestParam Map<String, String> map) {
    System.out.println(map);
    return "main";
}
```

### @RequestMapping 패턴

```java
@RequestMapping("/hello")                       // 정확히 /hello 만
@RequestMapping(value={"/hello2", "/hello3"})   // /hello2 또는 /hello3 둘 다
@RequestMapping(value="/yyy*")                  // /yyy 로 시작하는 모든 URL
@RequestMapping(value="/zzz/*")                 // /zzz/xxx (경로 1단계)
@RequestMapping(value="/kkk/**")                // /kkk/xxx/yyy (경로 여러 단계)
@RequestMapping(value="/aaa/*/bbb")             // 중간에 특정경로 1개
@RequestMapping(value="/ccc/**/ddd")            // 중간에 특정경로 여러개
```

### 클래스 레벨 @RequestMapping과 GET/POST 구분

```java
@Controller
@RequestMapping("/member")
public class MemberController {

    // 실제 URL: http://localhost:8080/member/hello
    @GetMapping("/hello")
    public String hello() { 
        return "hello"; 
    }

    // GET 요청 → 폼 화면 보여주기
    @GetMapping("/join")
    public String joinForm() {
        return "joinForm";
    }

    // POST 요청 → 폼 제출 처리
    @PostMapping("/join")
    public String join(LoginDTO dto) {
        return "redirect:/list";
    }

    // 실제 URL: http://localhost:8080/member/list
    @GetMapping("/list")
    public String list() { 
        return "list"; 
    }
}
```
