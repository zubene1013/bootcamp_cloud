## Key concepts learned

- **S3 Object 스토리지**: AWS의 파일 보관 서비스로 무한 대여 방식, Bucket > Object > Key 구조를 가지며 사용한 만큼만 과금
- **Storage Class**: Standard(자주 접근)부터 Glacier(거의 안 쓰는 아카이브용)까지 있으며, 저렴할수록 꺼내는데 오래 걸림
- **S3 기본 Private 설정**: 모든 버켓은 생성 시 기본이 Private이며, 공개하려면 명시적으로 퍼블릭 액세스 차단을 해제해야 함
- **IAM 역할 vs IAM 사용자**: 역할은 리소스에 붙는 자동 갱신되는 출입권(EC2용), 사용자 액세스키는 수동 관리되는 열쇠(AWS 외부 앱용)
- **보안그룹 vs IAM**: 보안그룹은 네트워크 접근 통제, IAM은 AWS 서비스 API 호출 권한 제어
- **S3 버전 관리**: 객체의 생성/수정/삭제 이력을 버전별로 보관하며, 삭제는 Delete Marker만 추가되고 복원 가능
- **S3 버전 관리 비활성화**: 한번 켜면 비활성화 불가하고 중지(Suspend)만 가능

## Commands / Configuration

### EC2에서 S3 파일 다운로드

```bash
aws s3 cp s3://bucket-name/file-name .
```

### IAM 액세스키 설정 및 S3 파일 다운로드

```bash
aws configure
# Access Key ID, Secret Access Key, Region 입력
aws s3 cp s3://bucket-name/project.zip .
```

### SpringBoot 프로젝트 빌드

```bash
./gradlew clean build -x test
```

### 빌드된 JAR 파일 실행

```bash
java -jar build/libs/project.jar
```

### nohup을 이용한 백그라운드 실행 및 로그 확인

```bash
sudo nohup java -jar build/libs/project.jar &
sudo tail -f nohup.out
```

### 버킷 정책 예시 (이미지 공개)

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::bucket-name/*"
    }
  ]
}
```
