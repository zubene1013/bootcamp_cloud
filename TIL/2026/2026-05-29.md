## Key concepts learned

- **useradd**: 새로운 사용자를 생성하는 명령어로 -m(홈디렉터리 생성), -d(경로 지정), -g(Primary Group 지정), -G(Secondary Group 지정), -s(쉘 지정) 옵션 사용 가능
- **passwd**: 사용자의 비밀번호를 설정하거나 변경하는 명령어
- **userdel**: 사용자를 삭제하며 -r 옵션으로 홈디렉터리까지 함께 삭제 가능
- **Primary Group vs Secondary Group**: Primary Group은 id 명령어로 확인되는 기본 그룹이고, Secondary Group은 groups 명령어로 확인되는 추가 그룹
- **chmod 기호 모드**: u(소유자), g(그룹), o(기타)에 +(부여), -(취소), =(설정) 연산자로 r(읽기), w(쓰기), x(실행) 권한 관리
- **chmod 숫자 모드**: r=4, w=2, x=1로 각 권한을 합산하여 3자리 숫자(소유자/그룹/기타)로 표현
- **파일 접근 권한**: 읽기(r), 쓰기(w), 실행(x) 3가지 권한으로 파일에 대한 무단 접근 방지
- **프로세스(Process)**: 실행 중인 프로그램을 의미하며 부모/자식 관계로 계층적으로 구성되고 PID로 고유하게 식별됨
- **PID(프로세스 아이디)**: 모든 프로세스가 가지는 고유 식별자로 작은 번호일수록 중요한 프로세스
- **ps 명령어**: 프로세스 상태를 확인하며 ps -ef로 모든 프로세스 조회 가능

## Commands / Configuration

### 사용자 생성 및 관리

```bash
# 사용자 생성
sudo useradd [옵션] 사용자명

# 기본 사용자 생성
sudo useradd -m user2

# 홈디렉터리 경로 지정
sudo useradd -m -d /home/project/user3 user3

# Primary Group 지정
sudo useradd -m -g dev user4

# Secondary Group 지정
sudo useradd -m -G sudo,users user5

# 쉘 지정
sudo useradd -m -s /bin/bash user6

# 비밀번호 설정
sudo passwd user2

# 사용자 전환
su user2

# 사용자 삭제
sudo userdel -r user6
```

### 사용자 그룹

```bash
# Primary Group 확인
id 사용자명

# Secondary Group 확인
groups 사용자명

# 그룹 생성
sudo groupadd 그룹명

# 그룹 생성 후 사용자 추가
sudo groupadd dev
sudo useradd -m -g dev user4
```

### 파일 접근 권한 관리 (chmod)

```bash
# 기호 모드
chmod u+w exam.txt              # 소유자에 쓰기 권한 부여
chmod u+rwx exam.txt            # 소유자에 읽기/쓰기/실행 부여
chmod o+r exam.txt              # 기타에 읽기 부여
chmod g-w exam.txt              # 그룹에서 쓰기 취소
chmod ug=rwx,o= exam.txt        # 소유자/그룹은 rwx, 기타는 권한 모두 취소

# 숫자 모드
chmod 745 exam.txt              # rwxr--r-x
chmod 641 exam.txt              # rw-r----x
chmod 600 exam.txt              # rw-------
```

### 프로세스 조회

```bash
ps                  # 현재 터미널에서 실행한 프로세스만 출력
ps -ef              # 모든 프로세스 출력
ps -ef | grep java  # java 프로세스만 필터링
```
