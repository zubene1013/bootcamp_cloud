## Key concepts learned

- **Java Platform 3가지**: Java SE, Java EE, Java ME의 구분 및 웹 개발에 필요한 플랫폼 이해
- **웹 애플리케이션 배포 구조**: Tomcat webapps 아래의 폴더 구조와 WEB-INF 폴더의 보안 중요성
- **Dynamic Web Project**: 웹 프로젝트 생성 시 context root의 중요성 및 web.xml 자동 생성 필요
- **JSP 처리 3단계**: JSP 파일이 Java 파일로 변환되고 컴파일되어 실행되는 과정
- **Servlet 계층구조**: Servlet → GenericServlet → HttpServlet 상속 관계
- **Servlet 라이프사이클**: 서블릿은 단 1번만 생성되고 여러 사용자 요청을 처리하는 구조
- **인스턴스 변수 vs 로컬 변수**: 공유 데이터 문제 방지를 위해 로컬 변수 사용의 중요성
- **Servlet Mapping**: 어노테이션 @WebServlet과 web.xml을 이용한 URL 매핑 방법
- **HttpServletRequest**: 폼 데이터 조회 메서드(getParameter, getParameterValues, getParameterNames)
- **HttpServletResponse**: MIME 타입 지정, PrintWriter를 이용한 HTML 출력
- **Scope 개념**: request(단일 요청), session(사용자별 세션), application(전체 애플리케이션) 범위의 데이터 관리
- **Filter**: 서블릿 요청 전/후에 처리할 작업을 구현하는 기능, FilterChain을 이용한 체이닝
- **MyBatis**: XML 기반 SQL 매핑 라이브러리를 이용한 DB 연동 구조

### Servlet 기본 구조

```java
package com.servlet;

import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

public class HelloServlet extends HttpServlet {

    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) {
        // GET 요청 처리
    }

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) {
        // POST 요청 처리
    }
}
```

### Servlet 매핑 — 어노테이션 (권장)

```java
@WebServlet("/hello")
public class HelloServlet extends HttpServlet { ... }
```

### Servlet 매핑 — web.xml

```xml
<servlet>
    <servlet-name>HelloServlet</servlet-name>
    <servlet-class>com.servlet.HelloServlet</servlet-class>
</servlet>
<servlet-mapping>
    <servlet-name>HelloServlet</servlet-name>
    <url-pattern>/hello</url-pattern>
</servlet-mapping>
```

### HttpServletResponse를 이용한 HTML 출력

```java
// 1단계: MIME타입 지정
response.setContentType("text/html;charset=UTF-8");

// 2단계: 출력 객체 가져오기
PrintWriter out = response.getWriter();

// 3단계: HTML 출력
out.print("<html>");
out.print("<body>");
out.print("<h1>Hello</h1>");
out.print("</body>");
out.print("</html>");
```

### HttpServletRequest를 이용한 요청 데이터 조회

```java
// 단일 값 조회
String username = request.getParameter("username");

// 복수 값 조회
String[] hobbies = request.getParameterValues("hobby");

// 전체 파라미터 조회
Enumeration<String> enu = request.getParameterNames();
while (enu.hasMoreElements()) {
    String key = enu.nextElement();
    String value = request.getParameter(key);
}
```

### Request Scope

```java
// 저장
request.setAttribute("key", object);
// 조회
Object obj = request.getAttribute("key");
// 삭제
request.removeAttribute("key");
```

### Session Scope

```java
// 세션 가져오기 (없으면 새로 생성)
HttpSession session = request.getSession();

// 저장
session.setAttribute("key", object);
// 조회
Object obj = session.getAttribute("key");
// 삭제
session.removeAttribute("key");
```

### Application Scope

```java
ServletContext ctx = getServletContext();

// 저장
ctx.setAttribute("key", object);
// 조회
Object obj = ctx.getAttribute("key");
// 삭제
ctx.removeAttribute("key");
```

### Filter 구현

```java
package com.filter;

import jakarta.servlet.*;
import jakarta.servlet.annotation.WebFilter;
import java.io.IOException;

@WebFilter("/*")
public class MyFilter implements Filter {

    @Override
    public void doFilter(ServletRequest request,
                         ServletResponse response,
                         FilterChain chain)
                         throws IOException, ServletException {
        // 선처리 (요청 전)
        System.out.println("요청 전 처리");

        chain.doFilter(request, response);

        // 후처리 (응답 후)
        System.out.println("응답 후 처리");
    }
}
```

### Filter web.xml 매핑

```xml
<filter>
    <filter-name>MyFilter</filter-name>
    <filter-class>com.filter.MyFilter</filter-class>
</filter>
<filter-mapping>
    <filter-name>MyFilter</filter-name>
    <url-pattern>/*</url-pattern>
</filter-mapping>
```
