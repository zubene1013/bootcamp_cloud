## Key concepts learned

- **REST API**: 클라이언트와 서버 간 JSON으로 데이터를 주고받는 방법론으로, 웹 브라우저, 핸드폰, IoT 등 다양한 클라이언트가 동일한 API를 사용할 수 있음
- **@RestController**: @Controller와 @ResponseBody를 합친 어노테이션으로, JSON 응답을 반환하는 REST API 작성에 사용
- **@PathVariable**: URL 경로에 포함된 파라미터를 메서드의 인자로 바인딩하는 어노테이션
- **Lombok**: DTO 작성 시 생성자, getter/setter, toString을 자동으로 생성해주는 라이브러리
- **빌더 패턴**: 객체 생성 시 각 필드를 명확하게 지정하여 가독성을 높이는 디자인 패턴
- **ApiResponse**: success, message, data 필드를 포함하여 표준화된 응답 형식을 제공하는 제네릭 클래스
- **ResponseEntity**: HTTP 상태 코드와 응답 본문을 함께 제어할 수 있는 Spring 클래스
- **@RestControllerAdvice**: REST API의 전역 예외처리를 담당하며, JSON 형식으로 예외 응답을 반환

### ApiResponse 클래스 구현

```java
@AllArgsConstructor
@NoArgsConstructor
@Getter @Setter @ToString @Builder
public class ApiResponse<T> {

    boolean success;
    String message;
    T data;

    // 성공 응답
    public static <T> ApiResponse<T> ok(String message, T data) {
        return ApiResponse.<T>builder()
                .success(true)
                .message(message)
                .data(data)
                .build();
    }

    // 실패 응답
    public static <T> ApiResponse<T> fail(String message, T data) {
        return ApiResponse.<T>builder()
                .success(false)
                .message(message)
                .data(data)
                .build();
    }
}
```

### REST API CRUD Controller 구현

```java
@RestController
public class TodoController {

    TodoService service;
    public TodoController(TodoService service) {
        this.service = service;
    }

    // 1. 목록 조회
    @GetMapping("/todos")
    public ApiResponse<List<TodoDTO>> todos() {
        return ApiResponse.ok("Todo 목록조회 성공", service.findAll());
    }

    // 2. 단건 조회
    @GetMapping("/todos/{id}")
    public ApiResponse<TodoDTO> todoById(@PathVariable int id) {
        TodoDTO dto = service.findById(id);
        if (dto != null) {
            return ApiResponse.ok(id + " 조회 성공", dto);
        } else {
            return ApiResponse.fail(id + " 조회 실패", null);
        }
    }

    // 3. 저장
    @PostMapping("/todos")
    public ApiResponse<TodoDTO> createTodo(@RequestBody TodoDTO dto) {
        service.save(dto);
        return ApiResponse.ok("저장 성공", dto);
    }

    // 4. 수정
    @PutMapping("/todos/{id}")
    public ApiResponse<TodoDTO> updateTodo(@PathVariable int id,
                                           @RequestBody TodoDTO dto) {
        dto.setId(id);
        service.updateById(dto);
        return ApiResponse.ok("수정 성공", dto);
    }

    // 5. 삭제
    @DeleteMapping("/todos/{id}")
    public ApiResponse<Void> deleteTodo(@PathVariable int id) {
        service.deleteById(id);
        return ApiResponse.ok("삭제 성공", null);
    }
}
```

### ResponseEntity를 이용한 HTTP 상태 코드 제어

```java
// 목록 조회 - 200 OK
@GetMapping("/todos")
public ResponseEntity<ApiResponse<List<TodoDTO>>> getAllTodos() {
    ApiResponse<List<TodoDTO>> result = ApiResponse.ok("성공", service.findAll());
    return ResponseEntity.ok(result);
}

// 단건 조회 - 없으면 404
@GetMapping("/todos/{id}")
public ResponseEntity<ApiResponse<TodoDTO>> todoById(@PathVariable int id) {
    TodoDTO dto = service.findById(id);
    if (dto == null) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body(ApiResponse.fail("조회 실패", null));
    }
    return ResponseEntity.ok(ApiResponse.ok("조회 성공", dto));
}

// 저장 - 201 Created
@PostMapping("/todos")
public ResponseEntity<ApiResponse<TodoDTO>> addTodo(@RequestBody TodoDTO dto) {
    service.save(dto);
    URI location = ServletUriComponentsBuilder
            .fromCurrentRequest()
            .path("/{id}")
            .buildAndExpand(dto.getId())
            .toUri();
    return ResponseEntity.created(location).body(ApiResponse.ok("저장 성공", dto));
}

// 삭제 - 204 No Content
@DeleteMapping("/todos/{id}")
public ResponseEntity<ApiResponse<Void>> deleteTodo(@PathVariable int id) {
    service.deleteById(id);
    return ResponseEntity.noContent()
            .header("X-request-result", "delete")
            .build();
}
```

### REST API 예외처리

```java
// RecordNotFoundException.java
public class RecordNotFoundException extends RuntimeException {
    public RecordNotFoundException(String message) {
        super(message);
    }
}

// @RestControllerAdvice를 이용한 전역 예외처리
@RestControllerAdvice
public class RestGlobalExceptionHandler {

    @ExceptionHandler(RecordNotFoundException.class)
    public ResponseEntity<ApiResponse<Void>> handleException(Exception e) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body(ApiResponse.fail(e.getMessage(), null));
    }
}

// Controller에서 예외 발생
@GetMapping("/todos/{id}")
public ResponseEntity<ApiResponse<TodoDTO>> todoById(@PathVariable int id) {
    TodoDTO dto = service.findById(id);
    if (dto == null) {
        throw new RecordNotFoundException(id + " 조회 실패");
    }
    return ResponseEntity.ok(ApiResponse.ok("성공", dto));
}
```
