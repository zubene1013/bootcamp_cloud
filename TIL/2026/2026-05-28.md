## Key concepts learned

- **touch 명령어**: 파일을 생성하거나 기존 파일의 타임스탬프를 변경하는 명령어
- **mkdir 명령어**: 디렉터리를 생성하며, -p 옵션으로 중첩 디렉터리를 한 번에 생성 가능
- **cp 명령어**: 파일 및 디렉터리를 복사하며, -r 옵션으로 디렉터리 재귀 복사, -p 옵션으로 원본 속성 유지
- **mv 명령어**: 파일 및 디렉터리를 이동하거나 이름을 변경하는 명령어
- **rm 명령어**: 파일 및 디렉터리를 삭제하며, -r 옵션으로 중첩 디렉터리까지 삭제
- **find 명령어**: 파일명, 타입, 크기 등 다양한 조건으로 파일 및 디렉터리를 검색
- **grep 명령어**: 파일 내용에서 패턴을 검색하며, -E 옵션으로 여러 패턴 동시 검색 가능
- **하드 링크**: 같은 inode를 가지며, 한쪽 수정 시 다른 쪽도 영향을 받음
- **소프트 링크**: 바로가기처럼 작동하며, 원본 삭제 시 링크가 깨짐
- **tar 명령어**: 여러 파일을 묶음으로 만드는 명령어
- **gzip 명령어**: 파일을 압축하는 명령어
- **파이프(Pipe)**: | 기호를 사용하여 명령어의 출력을 다른 명령어의 입력으로 전달

## Commands / Configuration

### 파일 생성

```bash
touch 파일명
touch report.txt
stat report.txt
```

### 디렉터리 생성

```bash
mkdir [옵션] 디렉터리명
mkdir main sub
mkdir -p first/second/third
mkdir -v logs2
tree first
```

### 파일 및 디렉터리 복사

```bash
cp [옵션] 원본 대상
cp /etc/passwd ./users.txt
cp /etc/passwd ./logs2/users.txt
cp -i /etc/passwd ./users.txt
cp hello.txt users.txt first/
cp -r logs2 users.txt first/
sudo cp -p users.txt u2.txt
```

### 파일 및 디렉터리 이동 및 이름변경

```bash
mv [옵션] 원본 대상
mv dir1/dir3/a.txt dir1/dir3/aaa.txt
mv dir1/dir2/b.txt dir1/
mv dir1/*.txt dir1/dir2/
mv -n dir1/dir2/a.txt dir1/dir3/a.txt
mv -u dir1/dir2/a.txt dir1/dir4
```

### 파일 및 디렉터리 삭제

```bash
rm [옵션] 경로/파일
rm dir1/dir3/aaa.txt
rm -i dir1/dir4/a.txt
rm -rf dir1/
```

### 파일 및 디렉터리 찾기

```bash
find 경로 [옵션] 대상
find projects -name todo.txt
find projects -iname TODO.txt
find projects -name "to*.txt"
find projects -name todo2.txt -delete
sudo find /etc -name passwd -ls
find /etc -type d
find /etc -type f
find projects -name "*.log" -exec cat {} \;
find projects -name "*.log" -exec rm {} \;
sudo find /etc -maxdepth 1 -name passwd -ls
```

### 파일 내용 검색

```bash
grep [옵션] 검색패턴 파일명
grep ERROR app.log
grep -i "error" app.log
grep -n "ERROR" app.log
grep -c "ERROR" app.log
grep -v -n "ERROR" app.log
grep -r "todo" ./projects
grep -E "ERROR|INFO" app.log
```

### 하드 링크 생성

```bash
ln 원본파일 대상파일
echo "hello" > m.txt
ln m.txt m_copy.txt
ls -il
echo "world" >> m.txt
cat m.txt m_copy.txt
rm m.txt
```

### 소프트 링크 생성

```bash
ln -s 원본 대상
echo "hello" > m2.txt
ln -s m2.txt m2_copy.txt
ls -il
rm m2.txt
rm m2_copy.txt
mkdir temp
touch temp/test.txt
ln -s temp temp2
ls -al temp2
```

### 파일 묶음 및 압축

```bash
tar -cvf 묶음.tar 파일1 파일2
tar -xvf 묶음.tar
gzip 파일명
gzip -d 파일명.gz
tar -czvf 파일명.tar.gz 폴더/
tar -xzvf 파일명.tar.gz
tar -xzvf 파일명.tar.gz -C 폴더
tar -czvf projects.tar.gz projects/
rm -rf projects
tar -xzvf projects.tar.gz
tar -xzvf projects.tar.gz -C temp
```

### 파이프 사용

```bash
ps -ef | grep java
ls -lhs /etc | head -n 20
cat -n /var/log/auth.log | grep -a "authentication failure"
cat -n /var/log/auth.log | grep -a "authentication failure" | wc -l
wc -l /etc/passwd
```
