## Key concepts learned

- **Pod**: K8s에서 가장 작은 배포 단위이며, 컨테이너를 감싸는 논리적 단위. 1개 이상의 컨테이너를 포함할 수 있으며 같은 Pod 내 컨테이너들은 localhost로 통신하고 볼륨을 공유함
- **Pod 재시작과 IP 변경**: Pod이 재시작되면 IP가 변경되므로 직접 IP로 접근할 수 없고, Service를 통해 접근해야 함
- **Pod의 일회용 특성**: Pod 자체는 일회용이며 죽으면 Deployment가 새로운 Pod을 생성함
- **apiVersion**: YAML 리소스가 K8s API의 어느 그룹/버전에 속하는지 명시하는 필드로, 리소스 종류를 체계적으로 관리함
- **apiVersion 그룹 체계**: v1은 가장 안정된 핵심 그룹이며, 나중에 추가된 기능들은 별도 그룹(apps/v1, networking.k8s.io/v1 등)으로 분리됨
- **Volume**: Pod에서 데이터를 저장하기 위한 메커니즘으로 emptyDir, hostPath, ConfigMap·Secret, PV·PVC (static·dynamic)의 여러 타입이 존재함
- **Probe**: Pod의 상태를 모니터링하는 메커니즘으로 Liveness, Readiness, Startup 세 가지 종류가 있음

## Commands / Configuration

### apiVersion 종류별 사용법

```yaml
apiVersion: v1                    # Pod, Service, PV, PVC, ConfigMap, Secret
apiVersion: apps/v1               # Deployment
apiVersion: networking.k8s.io/v1  # Ingress
```
