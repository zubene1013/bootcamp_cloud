## Key concepts learned

- **docker start**: Created 또는 Stopped 상태의 컨테이너를 실행하는 명령어 (-a 옵션으로 포그라운드 실행 가능)
- **docker stop**: Running 중인 컨테이너를 Graceful Shutdown으로 정상 종료 (SIGTERM → SIGKILL 순서)
- **docker pause/unpause**: Running 중인 컨테이너를 일시정지 및 재개 (프로세스는 살아있음)
- **docker run**: pull + create + start를 한 번에 수행하는 명령어 (다양한 옵션 지원)
- **docker ps**: 현재 실행 중인 컨테이너 목록 조회 (-a로 모든 상태 컨테이너 조회 가능)
- **docker exec**: 실행 중인 컨테이너 내부에서 추가 명령 실행 (-it로 직접 접속 가능)
- **docker cp**: 컨테이너와 호스트 간 파일 및 디렉터리 복사
- **docker container inspect**: 컨테이너의 상세 정보 조회

## Commands / Configuration

### docker start

```bash
docker start f916eea5608e              # 컨테이너 ID로 시작
docker start my-nginx2 some-mysql     # 여러 개 동시 시작
docker create --name my-ubuntu -it ubuntu bash
docker start -ai my-ubuntu            # -a(attach) -i(interactive)
```

### docker stop

```bash
docker stop f916eea5608e              # ID로 종료
docker stop some-mysql my-nginx2      # 여러 개 동시 종료
docker stop -t 20 my-nginx            # 20초 후 종료
docker stop $(docker ps -q)           # 실행 중인 모든 컨테이너 종료
```

### docker pause / unpause

```bash
docker pause f916eea5608e             # Status: Up X minutes (Paused)
docker pause my-nginx2 some-mysql
docker unpause f916eea5608e my-nginx2 some-mysql
```

### docker run

```bash
docker run hello-world

docker run --name my-ubuntu -it ubuntu bash

docker run --name my-nginx -p 1234:80 nginx

docker run -d --name my-nginx2 -p 1235:80 nginx

docker run -d --name my-nginx3 -p 1236:80 -e MY_HOST=myapp -e MY_NAME=inky nginx

docker network create full-stack
docker run -d --name my-mysql -e MYSQL_ROOT_PASSWORD=1234 --network full-stack mysql:8.3

docker run -d --name my-nginx4 -p 1237:80 --rm nginx
docker stop my-nginx4
```

### docker ps

```bash
docker ps --filter status=running      # created|running|paused|restarting|exited|dead
docker ps --filter status=exited
docker ps --filter status=paused
docker ps --filter ancestor=nginx
docker ps --filter "name=my-ubuntu"
docker ps --filter network=net1
docker ps --filter publish=80

docker ps --format "{{.ID}}: {{.Image}}: {{.State}} :{{.Status}} : {{.Names}}"

docker stop $(docker ps -q)
```

### docker exec

```bash
docker run -d --name my-nginx -p 1234:80 nginx
docker run -d --name my-ubuntu ubuntu:24.04 sleep infinity
docker run -d --name my-mysql -e MYSQL_ROOT_PASSWORD=1234 mysql:8.3
docker run -d --name my-redis redis

docker exec my-nginx ls
docker exec my-nginx pwd
docker exec my-ubuntu ls
docker exec my-ubuntu ps -ef
docker exec my-ubuntu env
docker exec my-ubuntu touch test.txt

docker exec -it my-nginx bash
docker exec -it my-ubuntu bash

docker exec -it my-mysql bash
```

### docker cp

```bash
docker cp test.txt my-ubuntu:/home
docker exec -it my-ubuntu bash

docker exec my-ubuntu touch xyz.txt
docker cp my-ubuntu:/xyz.txt .

docker cp index.html my-nginx:usr/share/nginx/html/index.html
```
