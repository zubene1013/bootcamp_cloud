## Key concepts learned

- **Pod 리소스 요청/제한**: CPU(m 단위)와 Memory(Mi/Gi 단위)를 requests와 limits로 설정하여 Pod의 리소스 사용을 제어
- **Namespace**: 팀/환경별 격리, 이름 충돌 방지, 접근 제어와 자원 제한의 적용 단위
- **Labels & Selector**: Pod에 메타데이터로 추가되는 키-값 쌍으로 리소스 식별 및 선택의 기준
- **ReplicaSet**: 항상 N개의 Pod이 살아있도록 보장하는 컨트롤러로, Pod 죽음 시 자동 생성 및 스케일링 담당
- **Deployment**: ReplicaSet을 자동으로 생성/관리하며 롤링 업데이트와 롤백을 지원하는 상위 컨트롤러
- **롤링 업데이트**: 신버전 Pod을 하나씩 생성하면서 구버전을 삭제하여 서비스 중단 없이 이미지 버전 변경
- **롤백**: 구버전 ReplicaSet을 보존했기 때문에 빠르게 이전 상태로 복구 가능
- **kubectl 문법**: `kubectl [command] [TYPE] [NAME] [flags]` 공식 구조로 모든 명령어 구성
- **kubeconfig**: kubectl이 클러스터 접속 정보를 참조하는 설정 파일로, clusters/contexts/users 3가지 요소로 구성
- **Context**: kubeconfig에서 클러스터-사용자-네임스페이스를 조합한 설정으로, 로컬/EKS 간 전환 가능
- **YAML Manifest**: apiVersion/kind/metadata/spec 구조로 선언형 설정을 정의하는 K8s 표준 파일 형식
- **EKS**: AWS가 K8s Control Plane을 관리하는 서비스로, 개발자는 Worker Node와 Pod 관리만 담당

## Commands / Configuration

### Pod 리소스 관리

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: stress-cpu
spec:
  restartPolicy: Never
  containers:
  - name: stress
    image: polinux/stress
    args: ["stress", "--vm", "1", "--vm-bytes", "300M", "--timeout", "120s", "--verbose"]
    resources:
      requests:
        cpu: "200m"
        memory: "64Mi"
      limits:
        cpu: "500m"
        memory: "128Mi"
```

```bash
kubectl apply -f pod-resource.yaml
kubectl get pod stress-cpu -w
kubectl describe pod stress-cpu
kubectl delete pod stress-cpu
```

### Namespace

```bash
kubectl create namespace dev
kubectl get ns
kubectl apply -f nginx-pod.yaml -n dev
kubectl get pod -n dev
kubectl get pod
kubectl get pod -A
kubectl delete ns dev
```

### ReplicaSet

```yaml
apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: nginx-replicaset
spec:
  replicas: 3
  selector:
    matchLabels:
      app: web
  template:
    metadata:
      labels:
        app: web
    spec:
      containers:
      - name: nginx-container
        image: nginx
        ports:
        - containerPort: 80
```

```bash
kubectl apply -f replicaset.yaml
kubectl get pods
kubectl delete pod nginx-replicaset-XXXXX
kubectl get pods
kubectl scale replicaset nginx-replicaset --replicas=5
kubectl scale replicaset nginx-replicaset --replicas=2
kubectl delete replicaset nginx-replicaset
```

### Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx-container
        image: nginx:1.25
        ports:
        - containerPort: 80
```

```bash
kubectl apply -f deployment.yaml
kubectl get pods
kubectl get deployment
kubectl get replicaset
```

### 롤링 업데이트

```bash
kubectl set image deployment/nginx-deployment nginx-container=nginx:1.27
kubectl get pods
kubectl get replicaset
```

### 롤백

```bash
kubectl rollout undo deployment/nginx-deployment
kubectl get replicaset
```
