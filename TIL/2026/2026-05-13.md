## Key concepts learned

- **프로파일(Profile)**: 개발환경, 테스트환경, 운영환경 등 다양한 환경에서 코드 수정 없이 설정을 분리하여 관리하는 방법
- **JdbcTemplate**: Spring JDBC에서 기존의 반복 코드(보일러플레이트)를 제거하고 단순화된 DB 접근 방법
- **H2 Database**: 설치 없이 의존성만 추가하여 사용 가능한 인메모리 DB
- **SqlSessionTemplate**: MyBatis에서 Spring이 자동으로 생성하는 SqlSession 대체 객체

## Commands / Configuration

### 프로파일 설정

```yaml
# application.yml - 공통 설정
spring:
  profiles:
    active: dev
```

```yaml
# application-dev.yml
my:
  email: dev@example.com
```

```yaml
# application-prod.yml
my:
  email: prod@example.com
```

```bash
# 실행 시 프로파일 지정 (CommandLine - yml보다 우선순위 높음)
java -jar myapp.jar --spring.profiles.active=prod
```

### 프로파일로 빈 관리

```java
@Component
@Profile("prod")
public class ProdClass {
    public ProdClass() {
        System.out.println("운영환경 빈 생성!");
    }
}

@Configuration
public class ProfileConfiguration {
    @Bean
    @Profile("prod")
    public String createProd() {
        return "prod 관련 객체 생성";
    }
}
```

### JdbcTemplate DAO 구현

```java
@Repository
public class TodoDAO {
    private final JdbcTemplate jdbcTemplate;

    public TodoDAO(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    public List<Map<String, Object>> findAll() {
        return jdbcTemplate.queryForList("SELECT * FROM todo");
    }

    public Map<String, Object> findById(int id) {
        return jdbcTemplate.queryForMap("SELECT * FROM todo WHERE id = ?", id);
    }

    public int insert(int id, String name, String job) {
        return jdbcTemplate.update("INSERT INTO todo (id, name, job) VALUES (?, ?, ?)", id, name, job);
    }

    public int delete(int id) {
        return jdbcTemplate.update("DELETE FROM todo WHERE id = ?", id);
    }
}
```

### MyBatis Repository 구현

```java
@Repository
public class TodoMyBatisRepository {
    @Autowired
    SqlSessionTemplate template;

    public List<TodoDTO> findAll() {
        return template.selectList("TodoMapper.findAll");
    }
}
```

### TodoMapper.xml

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="TodoMapper">
    <select id="findAll" resultType="TodoDTO">
        SELECT * FROM todo
    </select>
</mapper>
```
