## Key concepts learned

- **@RequestHeader**: 서블릿의 Enumeration 방식 대신 간단하게 헤더 값을 받기
- **@CookieValue**: 서블릿의 배열 방식 대신 간단하게 쿠키 값을 받기
- **멀티값 요청처리**: 같은 name으로 여러 값이 전송되는 경우 String 배열, List, DTO의 List 필드로 처리
- **Model 객체**: request scope 데이터를 View로 전달하는 가장 권장되는 방식
- **@SessionAttributes**: 특정 모델 속성을 session scope에 저장하여 여러 요청에서 유지
- **ModelAndView**: 뷰 정보와 모델 정보를 한 번에 설정하는 방식
- **@RequestBody**: JSON 형식의 요청 데이터를 DTO로 자동 변환
- **@ResponseBody**: 반환 값을 JSON으로 자동 변환하여 응답
- **forward vs redirect**: forward는 URL 변경 없이 내부 이동, redirect는 새 요청으로 URL 변경
- **Flash scope**: redirect 후에도 데이터를 유지하기 위한 scope (RedirectAttributes 사용)
- **PRG 패턴**: POST 요청 후 redirect로 GET 요청으로 전환하여 멱등성 문제 해결
- **Filter**: DispatcherServlet 앞단에서 모든 요청/응답에 공통 로직 적용
- **Interceptor**: DispatcherServlet 이후 Controller 단계에서 요청을 가로채 처리
- **@ExceptionHandler**: 선언적으로 특정 예외에 대한 처리 메서드 지정
- **@ControllerAdvice**: 모든 Controller에서 발생하는 예외를 일괄 처리하는 전역 예외처리

## Commands / Configuration

### HTTP 요청 처리

```java
// 헤더 값 얻기
@GetMapping("/main2")
public String main2(
        @RequestHeader(name = "user-agent") String userAgent,
        @RequestHeader(name = "connection") String connection) {
    System.out.println("user-agent: " + userAgent);
    System.out.println("connection: " + connection);
    return "main";
}

// 쿠키 값 얻기
@GetMapping("/get2")
public String main3(@CookieValue("userid") String userid) {
    System.out.println(userid);
    return "main";
}
```

### 멀티값 요청처리

```java
// String 배열로 받기
@GetMapping("/login2")
public String login2(
        @RequestParam("userid") String userid,
        @RequestParam("email") String[] email) {
    System.out.println(Arrays.toString(email));
    return "loginForm";
}

// List로 받기
@GetMapping("/login3")
public String login3(
        @RequestParam("userid") String userid,
        @RequestParam("email") List<String> email) {
    System.out.println(email);
    return "loginForm";
}

// DTO 필드를 List로 선언
@GetMapping("/login")
public String login(LoginDTO loginDTO) {
    System.out.println(loginDTO.getEmail());
    return "loginForm";
}
```

### Model을 이용한 View 데이터 전달

```java
// Model 객체 (가장 권장)
@GetMapping("/m2")
public String main2(Model model) {
    model.addAttribute("userid", "inky4832");
    model.addAttribute("email", "inky4832@exam.com");
    return "main2";
}

// Map으로 전달
@GetMapping("/m3")
public String main3(Map<String, String> map) {
    map.put("userid", "inky4832");
    return "main3";
}

// @ModelAttribute로 DTO 자체를 모델로
@GetMapping("/m4")
public String main4(@ModelAttribute("xxx") LoginDTO dto) {
    dto.setUserid("inky4832");
    return "main4";
}

// ModelAndView로 뷰 + 모델 한번에
@GetMapping("/m6")
public ModelAndView main6() {
    ModelAndView mv = new ModelAndView();
    mv.setViewName("main6");
    mv.addObject("userid", "inky4832");
    return mv;
}
```

### Session Scope 설정

```java
@Controller
@SessionAttributes(names = {"bbb", "ccc"})
public class MainController {

    @GetMapping("/k")
    public String main(Model model) {
        model.addAttribute("aaa", "hong1");  // request scope
        model.addAttribute("bbb", "hong2");  // session scope
        model.addAttribute("ccc", "hong3");  // session scope
        return "target";
    }
}
```

### Redirect와 Forward

```java
// forward - URL 변경 없음
@GetMapping("/aaa")
public String aaa() {
    return "forward:list";
}

// redirect - URL 변경됨
@GetMapping("/bbb")
public String bbb() {
    return "redirect:list";
}

// flash scope - redirect 후 데이터 유지
@GetMapping("/flash")
public String flash(RedirectAttributes model) {
    model.addFlashAttribute("userid", "inky");
    return "redirect:main";
}
```

### Filter 구현

```java
public class MyFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {
        System.out.println("요청 filter");
        chain.doFilter(request, response);
        System.out.println("응답 filter");
    }
}

@Configuration
public class FilterWebConfig {
    @Bean
    public FilterRegistrationBean<MyFilter> filterRegistrationBean() {
        FilterRegistrationBean<MyFilter> bean =
            new FilterRegistrationBean<>(new MyFilter());
        bean.addUrlPatterns("/*");
        return bean;
    }
}
```

### Interceptor 구현

```java
@Component
public class MyInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request,
                             HttpServletResponse response, Object handler) {
        System.out.println("preHandle");
        return true;
    }

    @Override
    public void postHandle(HttpServletRequest request,
                           HttpServletResponse response, Object handler,
                           ModelAndView modelAndView) {
        System.out.println("postHandle");
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
                                HttpServletResponse response,
                                Object handler, Exception ex) {
        System.out.println("afterCompletion");
    }
}

@Configuration
public class InterceptorWebConfig implements WebMvcConfigurer {

    @Autowired
    MyInterceptor myInterceptor;

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(myInterceptor)
                .addPathPatterns("/main", "/aaa/*");
    }
}
```

### 예외처리

```java
// 로컬 예외처리 - 특정 Controller
@Controller
public class MainController {

    @GetMapping("/main")
    public String main() {
        throw new IllegalArgumentException("예외 발생");
    }

    @ExceptionHandler(value = {IllegalArgumentException.class, NullPointerException.class})
    public String handleException(Exception ex, Model model) {
        model.addAttribute("message", ex.getMessage());
        return "error/error";
    }
}

// 전역 예외처리 - 모든 Controller
@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(value = {
        IllegalArgumentException.class,
        NullPointerException.class,
        ArithmeticException.class
    })
    public String handleException(Exception ex, Model model) {
        model.addAttribute("message", ex.getMessage());
        return "error/error";
    }
}
```
