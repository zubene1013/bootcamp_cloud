## Key concepts learned

- **Spring Profile**: 코드 변경 없이 application.yml의 active 값만 변경하여 dev(H2), prod(MySQL) 환경을 전환할 수 있는 설정 방식
- **DispatcherServlet**: Spring이 자동으로 생성하는 단일 서블릿으로, 모든 요청을 받아 URL을 보고 해당 Controller 메서드를 찾아 위임하는 핵심 컴포넌트
- **@Controller**: 클래스가 Controller임을 Spring에게 알리고 빈으로 등록하는 어노테이션
- **@RequestMapping**: URL 경로를 Controller 메서드에 매핑하여 요청 라우팅을 수행하는 어노테이션
- **Spring MVC 요청-응답 흐름**: 브라우저 요청 → DispatcherServlet → Controller → Service → DAO → DB → View → 브라우저 응답의 전체 사이클

## Commands / Configuration

### H2 + MySQL Profile 설정

#### build.gradle - 의존성
```groovy
implementation("org.mybatis.spring.boot:mybatis-spring-boot-starter:3.0.5")
runtimeOnly 'com.mysql:mysql-connector-j:8.3.0'
runtimeOnly 'com.h2database:h2'
implementation 'org.springframework.boot:spring-boot-starter-web'
```

#### application.yml - 공통 설정
```yaml
spring:
  profiles:
    active: dev

mybatis:
  mapper-locations: classpath*:com/**/TodoMapper.xml
  type-aliases-package: com.exam.dto
```

#### application-dev.yml - H2 설정
```yaml
server:
  port: 8080

spring:
  h2:
    console:
      enabled: true
  datasource:
    url: jdbc:h2:mem:testdb
    driver-class-name: org.h2.Driver
    username: sa
    password:
```

#### application-prod.yml - MySQL 설정
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/testdb
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: 1234
  sql:
    init:
      mode: always
```
