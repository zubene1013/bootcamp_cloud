## Key concepts learned

- **RequestDispatcher.forward()** - 요청을 다른 JSP/서블릿으로 전달하는 방법으로, 클라이언트 주소창 변화 없이 서버 내부에서 요청 처리 전환
- **IoC (Inversion of Control)** - 빈의 생성부터 소멸, 의존성 주입까지 IoC 컨테이너(ApplicationContext)가 담당하는 제어의 역행
- **Spring Framework** - Rod Johnson이 2003년 오픈소스로 시작한 EJB의 문제점을 해결하기 위한 엔터프라이즈 자바 프레임워크
- **선언적 트랜잭션 처리** - @Transactional 어노테이션으로 자동 commit/rollback 처리하는 Spring의 특징
- **REST API** - 다양한 클라이언트(웹, 모바일, IoT)에서 JSON 형식으로 통신하는 방식
- **POJO (Plain Old Java Object)** - 특정 플랫폼에 의존하지 않고 재사용 가능한 일반 자바 객체
- **Spring Bean** - POJO 기반의 Spring 애플리케이션에서 IoC 컨테이너가 관리하는 자바 클래스
- **의존성 주입 (DI)** - IoC 컨테이너가 객체의 의존성을 자동으로 주입하는 방식
- **@ComponentScan** - XXXApplication 클래스와 같거나 서브패키지 내에서 @Component 등의 어노테이션이 붙은 클래스를 자동으로 빈으로 등록
- **@Configuration + @Bean** - 외부 라이브러리 등 어노테이션을 직접 붙일 수 없는 경우 수동으로 빈을 생성하는 방법
- **생성자 주입 (Constructor-Based DI)** - 생성자 파라미터로 의존성을 받는 권장되는 의존성 주입 방식
- **필드 주입 (Field DI)** - @Autowired 어노테이션으로 필드에 직접 의존성을 주입하는 방식
- **빈의 스코프** - 싱글톤(기본값)은 하나의 빈을 여러 사용자가 재사용하고, prototype은 요청마다 새 객체 생성
- **@PostConstruct / @PreDestroy** - 빈의 초기화 및 종료 시점에 실행할 메서드를 지정하는 어노테이션
- **외부 설정값 관리** - application.yml이나 커맨드라인으로 코드 재컴파일 없이 실행 환경 정보를 관리
- **@Value** - 외부 설정값을 빈의 필드에 주입받는 방식
- **@ConfigurationProperties** - 관련된 설정값들을 하나의 클래스로 묶어서 관리하는 방식
- **Spring Boot Starters** - 개발에 필요한 여러 jar 파일들의 사전 구성된 묶음
- **빌드 도구 (Build Tool)** - 환경설정부터 배포까지의 복잡한 과정을 자동화하는 도구

## Commands / Configuration

### RequestDispatcher forward

```java
// 방법 1: 두 줄로 작성
RequestDispatcher dispatcher = request.getRequestDispatcher("target.jsp");
dispatcher.forward(request, response);

// 방법 2: 한 줄로 작성 (권장)
request.getRequestDispatcher("target.jsp").forward(request, response);
```

### Spring IoC Container 예제

```java
// 과거 방식 - 개발자가 직접 생성
BoardService service = new BoardServiceImpl(new BoardDAO());

// Spring 방식 - IoC Container가 생성 및 주입
@Autowired
BoardService service;  // IoC Container가 알아서 주입해줌
```

### Spring 선언적 트랜잭션 처리

```java
@Transactional  // 성공 → 자동 commit, 실패 → 자동 rollback
public int transaction(...) {
    // insert, delete 처리
}
```

### 빈 생성 방법 1 - 자동 스캔

```java
@Component    // 범용적으로 사용
@Service      // 서비스 레이어
@Controller   // 서블릿 역할 (View 반환)
@RestController // 서블릿 역할 (JSON 반환)
@Repository   // DAO 레이어
@Configuration // 추가 설정정보
public class MyClass { }
```

### 빈 생성 방법 2 - 다른 패키지인 경우

```java
// 패키지명으로 직접 지정
@SpringBootApplication(scanBasePackages = {"com.other"})

// 클래스 기준으로 지정 (더 안전)
@SpringBootApplication(scanBasePackageClasses = {com.other.EmpDAO.class})
public class DemoApplication {
    // ...
}
```

### 빈 생성 방법 3 - @Configuration + @Bean

```java
@Configuration
public class CustomerConfiguration {

    @Bean
    public Test create() {
        return new Test();
    }
}
```

### 생성자 주입 (권장)

```java
@Service
public class DeptServiceImpl {

    DeptDAO dao;

    public DeptServiceImpl(DeptDAO dao) {
        this.dao = dao;
    }
}
```

### 멀티 빈 주입

```java
@Service
public class DeptServiceImpl {

    DeptDAO dao;
    EmpDAO  empDao;

    public DeptServiceImpl(DeptDAO dao, EmpDAO empDao) {
        this.dao    = dao;
        this.empDao = empDao;
    }
}
```

### @Qualifier - 같은 타입 빈 지정

```java
@Service
public class DeptServiceImpl {

    CommonDAO dao;

    public DeptServiceImpl(@Qualifier("empRepository") CommonDAO dao) {
        this.dao = dao;
    }
}
```

### 필드 주입

```java
@Service
public class DeptServiceImpl {

    @Autowired
    private DeptDAO dao;
}
```

### 빈의 스코프 설정

```java
@Scope("prototype")
@Component
public class MyBean { }

// 상수를 이용한 방법 (오타 방지)
@Scope(ConfigurableBeanFactory.SCOPE_PROTOTYPE)
@Component
public class MyBean { }
```

### 빈의 초기화 및 종료 처리

```java
@Component
public class MyBean {

    @PostConstruct
    public void start() {
        System.out.println("빈 초기화 작업");
    }

    @PreDestroy
    public void shutdown() {
        System.out.println("자원 반납 작업");
    }
}
```

### @Value로 설정값 주입

```java
@Component
public class MyBean {

    @Value("${my.email}")
    private String email;

    @Value("${my.email:default@example.com}")
    private String emailWithDefault;
}
```

### @ConfigurationProperties로 설정값 관리

```java
@ConfigurationProperties(prefix = "my")
@Component
public class MyProperties {

    private String email;
    private String name;
    private int    port;

    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
    
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    
    public int getPort() { return port; }
    public void setPort(int port) { this.port = port; }
}
```
