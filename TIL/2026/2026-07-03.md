## Key concepts learned

- **인스턴스(Instance)** - EC2에서 생성한 가상 서버 1대, 반드시 하나의 가용영역(AZ)에만 존재하며 AZ 간 이동 불가
- **AMI(Amazon Machine Image)** - 서버 원본 이미지(OS+기본설정 묶음), EBS Snapshot 형태로 S3에 보관되며 새 인스턴스 복제에 사용
- **인스턴스 타입(Instance Type)** - 서버 하드웨어 사양 클래스(예: t3.micro = t시리즈 + 3세대 + micro크기)
- **보안그룹(Security Group)** - EC2에 연결되는 가상 방화벽, Inbound/Outbound Rule로 트래픽 제어
- **EBS(Elastic Block Store)** - EC2용 네트워크 기반 블록 스토리지, EC2와 같은 AZ에만 존재 가능
- **서브넷(Subnet)** - VPC 내를 더 작은 범위로 나눈 부분망, 반드시 하나의 AZ에만 속함
- **퍼블릭 서브넷** - 인터넷 게이트웨이(IGW)와 연결되어 외부 접근 가능한 서브넷(웹서버 배치용)
- **프라이빗 서브넷** - 외부와 직접 연결되지 않은 서브넷(DB서버 배치용, 보안)
- **인터넷 게이트웨이(IGW)** - VPC 전체가 인터넷과 연결되는 유일한 정문
- **라우팅 테이블** - 각 서브넷이 트래픽을 보내는 경로를 정의한 규칙북, "0.0.0.0/0 → IGW" 규칙으로 IGW 사용 가능
