## Key concepts learned

- **Amazon RDS (Relational Database Service)**: AWS가 설치/패치/백업/장애조치를 관리하는 완전관리형 관계형 DB 서비스로, DB 서브넷 그룹은 단일 AZ 배포여도 최소 2개 이상의 AZ에 걸친 서브넷을 지정해야 함
- **IAM 데이터베이스 인증**: 고정 비밀번호 대신 IAM 자격증명으로 발급받은 15분짜리 임시 토큰으로 DB에 로그인하는 보안 방식
- **RDS 마스터 계정의 권한 제한**: 마스터 계정도 SUPER/FILE/SHUTDOWN 같은 인프라급 권한은 갖고 있지 않으며, 본인이 안 가진 권한을 GRANT할 수 없음
- **k6 부하테스트**: 가상 사용자(VU)를 단계적으로 늘려 서버에 동시 요청을 보내 병목 지점을 찾는 도구로, VU 증가 시 응답시간(Duration)이 급상승하면 병목 신호
- **CloudWatch vs CloudWatch Agent**: 기본 CloudWatch는 CPU/Network만 측정하고, Agent 설치 후 메모리/디스크 같은 상세 지표를 CWAgent 네임스페이스에 수집
- **RDS 메모리 지표 방향**: RDS는 FreeableMemory(남은 메모리, 값이 낮을수록 부족)를 제공하며, EC2의 mem_used_percent(사용률)와 방향이 반대
- **Prometheus의 Pull 방식**: CloudWatch Agent의 Push 방식과 달리, Prometheus는 대상 서버를 주기적으로 조회해서 메트릭을 수집
- **K3s (경량 Kubernetes)**: 마스터(컨트롤플레인)와 워커 노드를 모두 자신이 관리하는 경량 Kubernetes 배포판
- **Kubernetes Deployment**: Pod 개수와 상태를 관리하는 리소스로, 원하는 상태(desired state)를 유지
- **Kubernetes Service(NodePort)**: 고정된 포트를 통해 클러스터 외부에서 Pod에 접근할 수 있게 해주는 리소스
- **ConfigMap과 Secret의 구분**: ConfigMap은 민감하지 않은 설정값(DB host/port)을, Secret은 민감한 값(계정/비밀번호)을 저장하며, Secret의 stringData는 반드시 문자열로 파싱돼야 함
- **imagePullSecrets**: Private ECR에서 이미지를 pull하기 위한 인증 정보를 Kubernetes Secret으로 저장
- **Rolling Update (무중단 배포)**: Deployment의 image 태그만 변경하면 기존 Pod를 한 번에 종료하지 않고 순차적으로 교체
- **K3s vs EKS**: K3s는 마스터+워커를 모두 자신이 관리하고, EKS는 AWS가 마스터(컨트롤플레인)를 관리하고 사용자는 워커 노드(EC2)만 관리

## Commands / Configuration

### RDS IAM 데이터베이스 인증

```sql
CREATE USER 'iamuser' IDENTIFIED WITH AWSAuthenticationPlugin AS 'RDS';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, DROP, ALTER ON *.* TO 'iamuser'@'%';
```

### CloudWatch Agent 설치

```bash
# CloudWatch Agent 다운로드 및 설치
wget https://s3.amazonaws.com/amazoncloudwatch-agent/ubuntu/amd64/latest/amazon-cloudwatch-agent.deb
dpkg -i -E ./amazon-cloudwatch-agent.deb
```

### k6 부하테스트

```bash
K6_WEB_DASHBOARD=true k6 run script.js
```

### Docker 설치 및 관리

```bash
# Docker 특정 버전 설치 및 고정
apt-get install docker-ce=5:28.5.1-1~ubuntu.24.04~noble
apt-mark hold docker-ce

# 신규 사용자 Docker 그룹 추가
usermod -aG docker $USER
newgrp docker
```

### K3s 설치

```bash
curl -sfL https://get.k3s.io | sh -
chmod 644 /etc/rancher/k3s/k3s.yaml
```

### Kubernetes Secret 생성 (ECR 인증)

```bash
kubectl create secret generic regcred --from-file=.dockerconfigjson=<경로> --type=kubernetes.io/dockerconfigjson
```

### EKS 클러스터 설정 (로컬 Windows PowerShell)

```bash
aws eks --region ap-northeast-2 update-kubeconfig --name <클러스터명>
```

### Prometheus 스크레이프 설정

```yaml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'spring-boot'
    static_configs:
      - targets: ['<프라이빗IP>:8080/actuator/prometheus']
```

### SpringBoot Actuator 설정

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,prometheus,metrics
```
