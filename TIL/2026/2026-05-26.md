## Key concepts learned

- **리눅스 커널(Kernel)**: 프로세스 관리, 파일시스템 관리, 메모리 관리을 담당하는 운영체제의 핵심
- **GNU 프로젝트**: 리처드 스톨만이 시작한 자유 소프트웨어 운동으로 GPL 라이선스 기반 소스코드 공개 의무화
- **리눅스 배포판**: 커널과 응용프로그램을 조합한 패키지로, Debian 계열(apt)과 레드햇 계열(dnf/yum)로 나뉨
- **쉘(Shell)**: 사용자가 리눅스 커널과 상호작용하기 위한 인터페이스로 명령해석과 프로그래밍 기능 수행
- **CIDR 표기법**: 네트워크 주소/비트마스크 형태로 IP 범위를 표현하는 방식 (예: 172.16.8.10/24)
- **NAT vs host-only**: NAT는 사설IP를 공용IP로 변환하여 인터넷 연결, host-only는 VM과 호스트 간 통신 전용
- **비대칭키 암호화**: SSH 접속 시 공개키는 서버에, 개인키는 클라이언트에 저장하여 비밀번호 없이 인증하는 방식
- **VMware 스냅샷**: 가상머신의 현재 상태를 저장하여 필요시 이전 상태로 복구 가능한 기능

## Commands / Configuration

### Ubuntu 초기 설정

```bash
# 모든 응용프로그램 업데이트
sudo apt update
sudo apt full-upgrade

# 터미널 설치
sudo apt install terminator
```

### SSH 서버 설치 및 실행

```bash
sudo apt install openssh-server
sudo systemctl status ssh
sudo systemctl start ssh
sudo systemctl enable ssh
```

### Windows PowerShell로 SSH 접속

```bash
ping 172.16.8.10
ssh user@172.16.8.10
```

### Ubuntu 고정 IP 설정

```
Address: 172.16.8.10
Gateway: 172.16.8.2
DNS:     8.8.8.8
NetMask: 24
CIDR 표기: 172.16.8.10/24
```

### pem 파일을 이용한 비밀번호 없는 SSH 접속

```bash
# 1. ubuntu에서 키 쌍 생성
ssh-keygen -q -N "" -f ubuntu_user1_key.pem

# 2. 공개키를 authorized_keys에 등록
cat ubuntu_user1_key.pem.pub > ~/.ssh/authorized_keys

# 3. 권한 설정
chmod 600 ~/.ssh/authorized_keys
```

MobaXterm에서 개인키로 접속:
- Session > SSH > Advanced SSH Setting
- Use Private Key: ubuntu_user1_key.pem 선택

### VMware 스냅샷 생성

