## Key concepts learned

- **Volume**: 컨테이너 삭제 후에도 데이터를 유지하기 위해 호스트의 스토리지를 마운트하는 방식, docker volume create로 생성
- **ENV 환경변수**: Dockerfile에서 기본값 설정 가능하며, docker run -e 옵션으로 덮어쓸 수 있음 (높은 우선순위)
- **Multi-stage Build**: 빌드 단계와 런타임 단계를 분리하여 이미지 크기를 대폭 감소 (1.35GB → 494MB)
- **Docker Network**: 컨테이너 간 통신을 위한 네트워크 환경, 동일 네트워크에서 컨테이너명으로 접근 가능
- **host.docker.internal**: Windows에서 호스트 PC의 서비스에 접근하기 위한 키워드
- **Docker Compose**: 여러 컨테이너를 YAML 파일로 정의하고 한 번에 관리하는 도구, 자동으로 동일 네트워크 구성
- **Kubernetes (K8s)**: 여러 서버에서 컨테이너를 자동으로 관리하는 오케스트레이션 플랫폼
- **Pod**: K8s에서 컨테이너를 실행하는 최소 단위, 1개 이상의 컨테이너 포함 가능
- **Service**: Pod에 고정된 접속 창구 제공, 여러 Pod으로 트래픽 분산
- **Control Plane**: K8s 클러스터 전체를 관리하는 마스터 노드
- **Worker Node**: 실제 컨테이너(Pod)가 실행되는 서버

## Commands / Configuration

### SpringBoot Docker Build & Run

```bash
# Gradle로 jar 생성
.\gradlew clean build -x test

# 이미지 빌드
docker build -t springboot21 .

# 컨테이너 실행
docker run -d --name springboot21 -p 8080:8080 springboot21
```

### Volume 활용

```bash
# Volume 생성
docker volume create spring-data

# Volume 마운트하여 컨테이너 실행
docker run -d --name springboot21 -p 8080:8080 -v spring-data:/app/upload springboot21
```

### ENV 환경변수 주입

```bash
# Dockerfile 기본값으로 실행
docker run -d --name springboot21 -p 8080:8080 springboot21

# 환경변수 덮어쓰기
docker run -d --name springboot21 -p 1234:9090 \
  -e SERVER_PORT=9090 \
  -e SPRING_PROFILES_ACTIVE=test \
  -e APP_MESSAGE=helloworld \
  springboot21
```

### Multi-stage Build Dockerfile

```dockerfile
# Build Stage
FROM gradle:8.10.2-jdk21 AS x

WORKDIR /build

COPY . .

RUN gradle clean bootJar -x test

# Runtime Stage
FROM eclipse-temurin:21-jre

WORKDIR /app

COPY --from=x /build/build/libs/*.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","app.jar"]
```

### Docker Network 설정

```bash
# 네트워크 생성
docker network create boot-mysql-net

# 네트워크로 MySQL 컨테이너 실행
docker run -it -d --name mysql-data3 -e MYSQL_ROOT_PASSWORD=1234 -e MYSQL_DATABASE=testdb \
  -v mysql-data-volume3:/var/lib/mysql --network boot-mysql-net mysql:8.3

# 동일 네트워크로 SpringBoot 컨테이너 실행
docker run -d --name spring-mysql-demo3 -p 8080:8080 --network boot-mysql-net spring-mysql-demo3
```

### Docker Compose 기본 구조

```yaml
services:
  web:
    image: nginx:latest
    ports:
      - "8080:80"

  db:
    image: postgres:18
    environment:
      POSTGRES_USER: example
      POSTGRES_DB: exampledb
    volumes:
      - type: bind
        source: ./proxy/nginx.conf
        target: /etc/nginx/conf.d/default.conf
        read_only: true
```

### Docker Compose 명령어

```bash
docker compose up -d      # 전체 컨테이너 백그라운드 시작
docker compose down       # 전체 컨테이너 중지 + 삭제
docker compose ps         # 실행 중인 서비스 확인
docker compose logs       # 전체 로그 확인
docker compose build      # 이미지 빌드
```

### Ubuntu에 Docker 설치

```bash
# Step 1 - 사전 패키지 설치
sudo apt-get update -y
sudo apt-get install ca-certificates curl -y
sudo install -m 0755 -d /etc/apt/keyrings

# Step 2 - Docker 공식 GPG 키 등록
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Step 3 - Docker apt 저장소 등록
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update -y

# Step 4 - Docker 28.5.1 설치
sudo apt-get install -y \
  docker-ce=5:28.5.1-1~ubuntu.24.04~noble \
  docker-ce-cli=5:28.5.1-1~ubuntu.24.04~noble \
  containerd.io \
  docker-buildx-plugin \
  docker-compose-plugin

# 버전 고정
sudo apt-mark hold docker-ce docker-ce-cli

# 설치 확인
sudo su -
docker version
docker run hello-world
```

### kubectl 주요 명령어

```bash
kubectl apply -f 파일.yaml           # Pod 생성/수정
kubectl get pods                      # Pod 목록
kubectl get pods -o wide              # 상세 정보 (IP, Node 포함)
kubectl describe pod <pod명>          # Pod 상세 조회
kubectl logs <pod명>                  # 로그 확인
kubectl delete pod <pod명>            # Pod 삭제
kubectl exec -it <pod명> -- bash      # 컨테이너 접속
kubectl port-forward pod/<pod명> 9090:80  # 포트 포워딩
```
